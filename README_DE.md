Ein Plugin. Mehrere Challenges. Eine zentrale Lobby.
Ein Minecraft-Paper-Plugin, das mehrere eigenständige Challenge-Spielmodi in einem gemeinsamen System vereint.

Deine Lieblings-Challenges an einem Ort!
</div>Hinweis: BastiGHG Challenges ist ein unabhängiges, inoffizielles Fanprojekt, das von Minecraft-Challenges von BastiGHG inspiriert wurde. Es besteht keine offizielle Verbindung, Unterstützung oder Zusammenarbeit mit BastiGHG.

<h2 align="center"><img src="images/buttons/headings/about-project.svg" width="550" alt="Über das Projekt"></h2>BastiGHG Challenges – Fanprojekt vereint mehrere Minecraft-Challenge-Spielmodi in einem einzigen Paper-Plugin.

Anstatt für jede Challenge ein separates Plugin installieren und verwalten zu müssen, können Spieler alle integrierten Games über eine gemeinsame Lobby erreichen.

Jedes Game besitzt eigene Welten, Spielerdaten, Einstellungen und Fortschritte. Die Verwaltung erfolgt über ein zentrales System.

Das Projekt wird kontinuierlich weiterentwickelt. Für zukünftige Versionen sind zusätzliche Challenges, Verbesserungen und neue Funktionen geplant.

Das Ziel: Eine zentrale Plattform für eine stetig wachsende Sammlung von Minecraft-Challenges.

</p>Die zentrale Lobby ist das Herzstück von BastiGHG Challenges.

Hier können Spieler die verfügbaren Challenges auswählen, laden, konfigurieren und verwalten.
Funktionen der Lobby
- Zentrale Spielauswahl und Verwaltung
- Dynamisches Laden und Entladen der Games
- Interaktive Displays und Schaltflächen
- Statusanzeigen und Ladeinformationen
- Zentrales Reset- und Abstimmungssystem
- Gemeinsame Verwaltung von Welteinstellungen
- Deutsche und englische Sprachunterstützung
- Eigene Logos, Icons und Oberflächengrafiken
  Jede Challenge läuft in einer eigenen Umgebung. Dadurch bleiben die Spielmodi voneinander getrennt, während Spieler zwischen ihnen wechseln können.

<h2 align="center"><img src="images/buttons/headings/installation.svg" width="550" alt="Installation"></h2>Voraussetzungen
Komponente	Benötigte Version
Minecraft	Java Edition
Serversoftware	Paper 26.3
Java	Java 25


Wichtig: Die aktuelle Version benötigt Paper 26.3. Paper 26.2 und ältere Versionen werden nicht unterstützt.
Erste Schritte
1. Lade die aktuelle BastiGHG-Challenges-`.jar` herunter.
2. Kopiere die Datei in den Ordner plugins deines Paper-Servers.
3. Starte den Minecraft-Server beziehungsweise starte ihn neu.
4. Betritt den Server und gehe in die zentrale Lobby.
5. Wähle die gewünschte Challenge aus, lade sie und starte das Game.
   Hauptbefehle
   Befehl	Beschreibung
   /lobby	Zur zentralen Lobby zurückkehren
   /language	Sprachauswahl öffnen
   /gamesettings	Einstellungen des ausgewählten Games öffnen
   /mobarmy	Befehle für MobArmyBattle
   /levelborder	Befehle für LevelBorder
   /levelblock	Befehle für LevelBlock


Je nach Game stehen weitere Info-Befehle und zusätzliche Funktionen zur Verfügung.
Hinweis: Die aufgeführten Befehle wurden aus der bisherigen englischen README übernommen und sollten noch mit der tatsächlichen plugin.yml abgeglichen werden.

<h2 align="center"><img src="images/buttons/headings/resource-pack.svg" width="550" alt="Ressourcenpaket"></h2>BastiGHG Challenges verwendet ein optionales Ressourcenpaket für die eigenen visuellen Elemente des Plugins.

Dazu gehören:
- Eigene Lobby-Logos
- Game-Icons
- Symbole für die Benutzeroberfläche
- Individuelle Displaygrafiken
  Das Ressourcenpaket wird beim Betreten des Servers automatisch angeboten.

Ohne das Ressourcenpaket können einige besondere Grafikelemente möglicherweise nicht korrekt angezeigt werden.
