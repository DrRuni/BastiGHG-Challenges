# LevelBlock Changelog

## v0.8

### Added

- Integration into BastiGHG Challenges – Fan Project
- Game selection and loading through the central lobby
- `/levelblock info` command
- Game settings menu
- Reset voting system
- `/levelblock reset`
- `/levelblock reset world`
- Separate player and game data
- Persistent game progress
- Support for central world settings

### Changed

- Player and world handling moved to the central challenge system
- Reset handling reworked
- Improved loading and saving of LevelBlock data

### Notes

- This version is currently considered Beta.
- Further multiplayer testing and bug fixes are planned.
