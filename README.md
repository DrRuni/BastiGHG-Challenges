### One Plugin. Multiple Challenges. One Central Lobby.

**A Minecraft Paper plugin combining multiple independent challenge games into one unified system.**


*All your favorite challenges in one place!*

</div>

> **Disclaimer:** BastiGHG Challenges is an independent, unofficial fan project inspired by Minecraft challenges played by BastiGHG. It is not affiliated with, endorsed by, or officially connected to BastiGHG.

---

<h2 align="center"><img src="images/buttons/headings/about-project.svg" width="550" alt="About the Project"></h2>


<p align="center">
  <strong>BastiGHG Challenges – Fan Project</strong> brings multiple Minecraft challenge game modes together in a single Paper plugin.
</p>

<p align="center">
  Instead of installing and managing separate plugins for every challenge, players can access all integrated games through one shared lobby.
</p>

<p align="center">
  Each game maintains its own worlds, player data, settings and progress while being managed by a centralized system.
</p>

<p align="center">
  The project is continuously developed with new challenge games, improvements and additional features planned for future releases.
</p>

<p align="center">
  <strong>The goal: One central platform for an expanding collection of Minecraft challenges.</strong>
</p>

<h2 align="center"><img src="images/buttons/headings/central-lobby.svg" width="550" alt="Central Lobby"></h2>

<p align="center">
  <img src="images/lobby.png" alt="Central Lobby" width="1200">
</p>


<p align="center">
  The central lobby is the heart of BastiGHG Challenges.
</p>

<p align="center">
  From here, players can select, load, configure and manage the available challenge games.
</p>

<h3 align="center">Lobby Features</h3>

<p align="center">
  Central game selection and management<br>
  Dynamic loading and unloading of games<br>
  Interactive displays and buttons<br>
  Game status and loading information<br>
  Centralized game reset and voting systems<br>
  Shared world settings and management<br>
  German and English language support<br>
  Custom logos, icons and interface graphics
</p>

<p align="center">
  Every challenge runs in its own environment, keeping different game modes separated while allowing players to switch between them.
</p>

<p align="center">
  <strong>Important:</strong> The current release requires Paper 26.3.
  Paper 26.2 and earlier versions are not supported.
</p>

<h3 align="center">Getting Started</h3>

<p align="center">
  1. Download the latest BastiGHG Challenges <code>.jar</code> file.<br>
  2. Place the file inside your Paper server's <code>plugins</code> folder.<br>
  3. Start or restart your Minecraft server.<br>
  4. Join the server and enter the central lobby.<br>
  5. Select, load and start your preferred challenge game.
</p>

    <tr>
      <td><code>/language</code></td>
      <td>Open the language selection</td>
    </tr>
    <tr>
      <td><code>/gamesettings</code></td>
      <td>Open the selected game's settings</td>
    </tr>
    <tr>
      <td><code>/mobarmy</code></td>
      <td>MobArmyBattle commands</td>
    </tr>
    <tr>
      <td><code>/levelborder</code></td>
      <td>LevelBorder commands</td>
    </tr>
    <tr>
      <td><code>/levelblock</code></td>
      <td>LevelBlock commands</td>
    </tr>
  </table>
