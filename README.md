# BastiGHG Challenges – Fan Project

A Minecraft Paper plugin that combines multiple challenge game modes into one central system.

> This is an unofficial fan project and is not affiliated with BastiGHG.

## Features

- Central lobby system
- Multiple challenge game modes
- Separate worlds and player data for each game
- Game selection and loading system
- World settings
- Reset and vote system
- Lobby displays and interactive buttons
- German and English language support
- Game progress can be saved
- Multiplayer support

## Included Games

### MobArmyBattle

Two teams compete against each other.
Players collect equipment, prepare mob waves for the opposing team and later fight through the enemy waves inside an arena.

Current internal version: `v1.7`

### LevelBorder

The world border grows based on the combined player levels.
The more levels the players collect, the larger the playable area becomes.

Current internal version: `v1.1`

### LevelBlock

The playable world expands block by block as the players progress.

Current internal version: `v0.8`


## Commands

Each game has its own main command:

```text
/mobarmy
/levelborder
/levelblock
```

For detailed game information:

```text
/mobarmy info
/levelborder info
/levelblock info
```

## Requirements

- Minecraft / Paper
- Java 25
- Paper 26.2

The plugin is currently developed and tested on recent Paper 26.2 builds.

## Installation

1. Download the plugin `.jar`
2. Place it inside your server's `plugins` folder
3. Start or restart the server
4. Join the lobby
5. Select and load a challenge game
